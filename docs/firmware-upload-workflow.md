# Firmware Upload Workflow

## Steps

1. Administrator logs into the management portal.
2. Selects the firmware image file.
3. Uploads the firmware to the server.
4. Server validates the firmware format.
5. SHA-256 hash is generated.
6. RSA digital signature is created.
7. Signed firmware is stored securely.
8. Firmware metadata is updated.
9. Firmware becomes available for authorized devices.

## Outcome

- Firmware uploaded successfully.
- Digital signature generated.
- Firmware ready for secure distribution.
